# MAP — where things live

A compact `file → responsibility` index. Read [AGENTS.md](../AGENTS.md) for conventions and
[docs/ROADMAP.md](./ROADMAP.md) for direction. The 2026-07-11 rebuild (R24) collapsed the old
four plugins into one; the 2026-08-08 MCP+skills rewrite (R100) retired the enforced core in
favor of the portable `mcp-server/` (any MCP-capable client, not just Claude Code, reaches the
same queue/ship/autopilot/board/burn-down/rework surface) plus advisory CLI scripts —
`secret-guard.sh` and `contract-guard.sh` stay deleted (R100/Pass 3). **Seven hooks now run**:
`prompt-continue.sh` (`UserPromptSubmit`, the one that never left) · `session-start.sh` +
`ask-guard.sh`, both REINSTATED in R100/Pass 6 (docs/adr/README.md R105) — the owner picked
"guaranteed context delivery" and "don't let the model barrel past an unanswered decision" back
over full portability for these two specifically, after watching a model ignore or subvert plugin
instructions it never had guaranteed in context — and `stop-autopilot.sh`, restored 2026-08-12
(forced continuation, bounded) and extended 2026-08-15 with the R82 burn-down hand-off (R114).
The plugin runs one loop — **propose → queue → drain** (R52): STEERING is now injected
automatically at session start (again) as well as on demand via `/companion:resume` · `tq` holds
it · autopilot drains it, and asking is blocked-and-parked again while it's armed · the credential
scanner (advisory, not a gate) flags shapes on request (see ROADMAP "The loop").

| `dev/mutate-gate.sh` | **The mutation gate** (R78) — `./check.sh --mutate [file…]` delegates here; extracted from `check.sh` at its 300-line cap, and (as with `doc-lint.sh`) so the SUITE can exercise it. Applies each declared mutation and requires the suite to redden. **"Caught" means a COMPLETE run that reported a failure, not merely a nonzero exit** — bats exits nonzero when KILLED (124, nothing run) and when it cannot gather tests (a well-formed `1..1 / not ok bats-gather-tests`, also nothing run), and scoring either as caught made this gate certify holes as covered, twice. Refuses (exit 2) three ways of measuring nothing: a **non-green baseline** (one pre-existing failure would score every mutation "caught"), a **concurrent run** on the same tree (they restore each other's `*.mutbak` and leave enforced core MUTATED), and an **unparseable suite**. Calibrates with `bats --count`, then requires plan == result-lines == that count with ≥1 failure; an incomplete run is retried once, then reported INCOMPLETE — never as coverage. A fake `bats` first on PATH drives every branch in its tests without recursing into the real suite. **`--validate`** checks every declared mutation still APPLIES to its target — in ~3 seconds, no suite run, so it lives in the DEFAULT gate. Stale patterns are this repo's single most repeated defect: seven orphaned by extractions and three by sed-delimiter collisions (a pattern containing the delimiter, e.g. `@{u}` or `"$@"` under `s@…@…@`), every one invisible locally and surfacing only on CI, where it reddens every shard at once. **`--shard N/M`** runs every Mth mutation (CI matrixes **10** shards, raised from 6 on 2026-08-22): 144 mutations x ~100s on CI is ~4 h serially (calibrated on the SLOWEST shard, not the average — the slowest is what sets wall-clock), and a long job blocks `gh run view --log-failed` for the WHOLE run — so a red check lane could not be read until the mutation lane finished. Shards are a true partition, gated by a test. **`--validate` also projects the CI wall-clock against R74's watch ceiling** and FAILS when the slowest shard can no longer finish inside it (WARN from 60%): `ci-watch.sh` gives up after `SHIP_CI_TIMEOUT` and reports SHIPPED-but-UNWATCHED, so an outgrown ceiling silently turns the enforced watch into a no-op that still reads like a guarantee — which happened twice (300s on 2026-08-01, 1800s on 2026-08-22) because the mutation count only ever grows and nothing compared the two.
