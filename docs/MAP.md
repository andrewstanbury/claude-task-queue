# MAP — where things live

A compact `file → responsibility` index. Read [AGENTS.md](../AGENTS.md) for conventions and
[docs/ROADMAP.md](./ROADMAP.md) for direction. The 2026-07-11 rebuild (R24) collapsed the old
four plugins into one; the 2026-08-08 MCP+skills rewrite (R100) retired the enforced core —
`secret-guard.sh`, `contract-guard.sh`, `ask-guard.sh`, `stop-autopilot.sh`, and `session-start.sh`
are all deleted — in favor of the portable `mcp-server/` (any MCP-capable client, not just Claude
Code, reaches the same queue/ship/autopilot/board/burn-down/rework surface) plus advisory CLI
scripts. **One hook survives**: `prompt-continue.sh` (`UserPromptSubmit`) — everything else that
used to block or force continuation is now prose the model can skip, an accepted trade (see
docs/adr/README.md R100). The plugin runs one loop — **propose → queue → drain** (R52):
`/companion:resume` seeds it, on demand · `tq` holds it · autopilot drains it · the credential
scanner (advisory now, not a gate) flags shapes on request (see ROADMAP "The loop").

Applies each declared mutation and requires the suite to redden. **"Caught" means a COMPLETE run that reported a failure, not merely a nonzero exit** — bats exits nonzero when KILLED (124, nothing run) and when it cannot gather tests (a well-formed `1..1 / not ok bats-gather-tests`, also nothing run), and scoring either as caught made this gate certify holes as covered, twice. A fake `bats` first on PATH drives every branch in its tests without recursing into the real suite. **`--validate`** checks every declared mutation still APPLIES to its target — in ~3 seconds, no suite run, so it lives in the DEFAULT gate. Stale patterns are this repo's single most repeated defect: seven orphaned by extractions and three by sed-delimiter collisions (a pattern containing the delimiter, e.g. `@{u}` or `"$@"` under `s@…@…@`), every one invisible locally and surfacing only on CI, where it reddens every shard at once. **`--shard N/M`** runs every Mth mutation (CI matrixes 6 shards): 65 mutations x a ~50s suite is ~55 min serially, and a long job blocks `gh run view --log-failed` for the WHOLE run — so a red check lane could not be read until the mutation lane finished. Shards are a true partition, gated by a test. |
