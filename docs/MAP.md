# MAP — where things live

A compact `file → responsibility` index. Read [AGENTS.md](../AGENTS.md) for conventions and
[docs/ROADMAP.md](./ROADMAP.md) for direction. The 2026-07-11 rebuild (R24) collapsed the old
four plugins into one; this reflects the current tree. The plugin runs one loop —
**propose → queue → drain** (R52): `session-start` seeds it · `tq` holds it · autopilot drains it ·
the secret gate guards every write (see ROADMAP "The loop").

## Repo root

| Path | Responsibility |
|---|---|
| `CLAUDE.md` | What this repo is + hard constraints + pointer to the steering doc. |
| `docs/REQUIREMENTS.md` | The **requirements ledger** — durable requirements/decisions with 🔒/🔓/⚰️ status. Source of truth. |
| `docs/ROADMAP.md` | Direction and backlog. |
| `docs/MAP.md` | This file. |
| `docs/GLOSSARY.md` | The companion's **coined vocabulary** — a *term → meaning* index (R37). Claude-facing, terse, **loaded on demand** (not injected each session); vocabulary only (gotchas → LESSONS, decisions → ledger). |
| `plugins/companion/tests/mutations.txt` | Declared mutations for `./check.sh --mutate` (R78) — one per line, `<file>::<sed>::<what it breaks>`. Each must turn the suite RED; one that stays green is a **hole** (a test that cannot fail), and a pattern that no longer matches is reported as a hole too, so the set can't rot. |
| `check.sh` | One-command gate: JSON valid · `claude plugin validate` · **version match (each `plugin.json` == its marketplace entry)** · ShellCheck · secret scan · 300-line size guard · bats. CI runs this. Also **`--mutate [file…]`** (R78, CI-only for the full set): applies each declared mutation and requires the suite to redden; **with file arguments it runs only the mutations targeting those files**, so the file you just edited can be checked on its own (R79). A `land`-time gate was built and removed pre-ship: ~6min for one diff against a 600s tool ceiling, and it would have mutated the live tree with `secret-guard.sh` active. Frontmatter is validated as a **strict flat `key: value` map** — the host parses it as YAML and drops the whole block on a throw, which a line-grep can't see (R75/R78) — and a ledger row stating a hard measurement must name where it was measured. |
| `.claude-plugin/marketplace.json` | Marketplace manifest (the one `companion` plugin). |

## plugins/companion — the whole system

| File | Responsibility |
|---|---|
| `STEERING.md` | **The steering layer** — the working agreement (queue discipline · challenge-the-ask + recommendation posture against the ledger · clean-as-you-go · autopilot). Two-tier (R69): the **core above the "injection stops here" marker** is what session-start injects (≤12KB, check-gated, marker exactly-once); the rationale below is on-demand reading. Not code, not a hook. |
| `bin/session-start.sh` | SessionStart hook: inject the STEERING **core** (above the marker, R69; fail-open to the whole file if no marker) once + re-surface this repo's open tasks from an earlier session (scoped by each session store's `.root` stamp — no native transcript, no cross-repo bleed) + surface the repo's `docs/LESSONS.md` gotchas if present (R30·d7). Fires on `source=compact` too → **re-anchors after a context compaction** (R30·d2), with a compaction-aware lead. Per-repo opt-outs (R50): a hand-written `steering=off` flag line skips the working-agreement injection; `CLAUDE_COMPANION_SECSCAN=0` disables the secret gate (the `/companion:features` CLI was removed 2026-07-18 — the flag mechanism + readers are unchanged). |
| `bin/secret-guard.sh` | PreToolUse[Write\|Edit] hook: the one **enforced** content-gate — block a write that would commit a credential (`exit 2`). `CLAUDE_COMPANION_SECSCAN=0` disables. |
| `docs/LESSONS.md` | This repo's accumulated **gotchas** (portability/test/CI traps) — model-maintained, injected each session by `session-start.sh` (R30·d7). Gotchas only; decisions live in the ledger, work in the queue. |
| `commands/advise.md` | `/companion:advise [target] [-- goal: X]` (R29/R32/R75) — independent brutal-honest **critique** of a target (default: whole project) via a critic panel; recommendation-first, one at a time, then queued. **Critique only — never edits.** Also the whole-project cleanliness sweep (absorbed `/companion:audit`, R32). |
| `commands/redesign.md` | `/companion:redesign [module]` (R54/R55/R75) — a named module runs **exactly one** bounded pass (D2 skipped; D0/D1 **narrowed to the module — weaker than the whole-app net, by construction**; D3/D4 identical); no argument = **whole-app** contract-preserving rebuild as a sequence of bounded, check-gated passes, with an up-front invariant-coverage gate (D0) + a **required `docs` first step** (D1); the per-module engine (R1–R5: bound → checks-first → regenerate → apply-on-branch → auto-revert-on-red) is inlined (absorbs the former `/companion:regen`, folded 2026-07-18 — a single bounded target is one pass). **Edits.** |
| `bin/tq` | **THE task queue** — the companion owns its store (`~/.claude/companion/tasks`, NOT native tasks). `add [--done "<acceptance>"]`/`doing`/`note`/`done-when`/`done`/`list`/`report`; a task's `done_when` (R30·d1) is its acceptance test, rendered in the report + resume so it survives a compaction. Mutations print a **one-line counts delta** (R69); the full report fires only at anchoring boundaries — `done`, `import`, explicit `report`, session-start/compact. **`export`/`import` (R60)** carry the open queue between machines over git — export to a path-free `.companion/queue.json`, import re-stamps it under the local repo path so cross-machine resume is path-tolerant (`/companion:resume` imports, `/companion:ship-it` exports). |
| `bin/resume.sh` | Manual resume — turn autopilot off (announced) + list this repo's open tasks from earlier sessions on demand (the SessionStart twin). Invoked by `/companion:resume` (R39). |
| `commands/ship-it.md` | `/companion:ship-it [pr] [--gate <cmd>]` (R75 args) — `ship.sh preflight` → **state the case** (risks / what-changes / R-IDs; devil's-advocate for consequential changes, R30·d6) + contract sync + message → `ship.sh land`. Judgment stays in the prompt; the mechanical spine runs on the rail (R71). |
| `bin/ship.sh` | The **deterministic rail** under ship-it (R71): `preflight` (gate → drift backstop → `tq export` → branch/status summary) and `land -F <msgfile>` (re-run gate → stage → refuse staged credential shapes → commit → **ff-only** merge to default → push → prune the shipped branch `-d`-only; merged sweep list-only unless `--prune-all`; then **enforce a bounded CI watch** — R74, `gh` run to conclusion, RED → exit 10 SHIPPED-fix-forward, best-effort/opt-out `SHIP_CI_WATCH=0`). Also `handoff` (R72): mid-flight cross-machine checkpoint — export + WIP commit (`wip/*` off the default) + push, **no gate**, secret backstop kept. Bails loudly with distinct exit codes (4 gate · 6 nothing · 7 non-ff · 8 push · 9 unsafe · 10 CI-red · 11 no `--da` on a declared critical path · 12 shipped-but-unwatched) — never `-D`, never the default branch, never force. |
| `commands/handoff.md` | `/companion:handoff` (R72) — thin wrapper over `ship.sh handoff`: checkpoint the working tree + queue to a pushed branch for pickup on another machine (pickup: `/companion:resume <branch>`). |
| `commands/resume.md` | `/companion:resume [branch]` (R39, re-split 2026-07-19; branch arg R75 — named is authoritative; a missing one skips the checkout but still runs the pickup, never guesses another branch) — **session pickup only**: runs `resume.sh` (autopilot off first + re-surface earlier-session tasks, class-preserving), reinstates them, then **hands off to `/companion:review`** for any parked/blocked among them. No longer walks the pile itself. |
| `commands/review.md` | `/companion:review` (R38, re-split 2026-07-19) — walk the **`❓ [parked]` + `⏳ [blocked]` backlog** one at a time, recommendation-first (reuses the advise loop, R29), writing picks back to `tq` before new work. **The autopilot-off trigger.** Parked+blocked only; defer/bail allowed; no-op when empty. |
| `commands/docs.md` | `/companion:docs [scope]` (R41/R75) — scan an existing repo for load-bearing, undocumented decisions and record them tiered (check › 🔒 › 🔓) + routed by R54 contract pillar (UX/NFR/invariant/incidental). The batch producer `advise` consumes; the JIT twin is a STEERING nudge. |
| `commands/cover.md` | `/companion:cover [scope]` (R58/R61/R75) — rank flows by criticality × coverage gap and **recommend then scaffold the ideal test** per critical flow in the repo's own runner, tagged to the flow so the R61 gate resolves it (buy-in first — asks before it writes). The test-scaffolding arm of the living contract. |
| `bin/ci-watch.sh` | The post-push CI watch (R74), extracted when `ship.sh` hit its 300-line cap (R79). `ci-watch.sh <sha>`: **0** green, or genuinely nothing to watch (no `gh`, no run registered, opted out) · **10** CI RED — shipped, fix forward · **12** a run was in flight and the watch gave up: **SHIPPED but UNWATCHED**, which used to be exit 0 and so read exactly like a pass (it let a red macOS ship through unremarked). |
| `bin/doc-lint.sh` | Two document checks the gate runs, extracted from `check.sh` so the SUITE can exercise them (R78 — check.sh runs bats, so anything inline there is untestable by construction). `frontmatter <file>…` lints the two keys the gate reads for shapes the host's YAML parser throws on (leading indicator · unquoted colon · unterminated quote · duplicate key) — a lint on known-bad shapes, **not** a YAML validator, deliberately scoped so it can't reject valid `allowed-tools:` sequences. `ledger <file>` requires a stated hard measurement to name where it was measured (approximations `~`/`≈` exempt at any length; a MISSING file is a loud FAIL, never a silent ok). **`fm <file>` is THE frontmatter reader** — one copy, used by `check.sh` too: it strips CR and a leading BOM, because a duplicated `awk` compared line 1 to `---` and a CRLF file therefore returned an EMPTY block, silently disabling every frontmatter check at once. Dev/ship-time only, not a hook. |
| `bin/contract-drift.sh` | The living-contract **backstop** (R58) — generic (R9) detector that warns when behaviour changed without a contract doc (`docs/flows/`·`INVARIANTS.md`) moving. Advisory (`exit 0`, never blocks); run by `check.sh` + `ship-it`. Prevention is the STEERING reflex; this is the net. |
| `bin/statusline.sh` | The status line (a `statusLine` command, not a hook), grouped by plugin-relevance (R34) with `:` dim section dividers: ⠋ beacon · `v<version>` (from plugin.json) · `:` active features `:` (each shown only when relevant — `🛡️✗` **only when the gate is off**, ✈️ autopilot / ✈️⚡ decisive R59, 📦 ship-mode; the whole section omitted when none active) · `:` 📋 open · ❓ parked · ⏳ blocked `:` (the queue, own section) · `:` **5h/7d account rate-limit bars** `:` · model · ⇡in ⇣out · project · branch (+ ↑ahead ↓behind). Read-only; beacon animates at `refreshInterval:10` (R81 — 3s cost ~212 CPU-s/hour/window, fork/exec-dominated). Git segment TTL-cached (`CLAUDE_COMPANION_SL_CACHE_TTL`, default 10s, `0` disables) so most repaints skip `git status`; branch/dirty may lag by the TTL. Shield 🛡️ carries VS16 for emoji-width parity with ✈️/📦. Wire with `/companion:setup`. **Account rate-limit bars (R76)**: `.rate_limits.{five_hour,seven_day}.used_percentage` straight off the same stdin payload — no API call, no network; 5-cell floor bar (only 100% fills), green/yellow/red at 60/85, `↻` reset countdown from 80%. Values are scrubbed of framing characters before joining — plain `join` does not escape what `@tsv` did, so a newline in a path would otherwise truncate the whole line. Absent for API-key users and pre-first-response, each window independently → renders nothing, never a zero. Reads the payload with a **US (0x1f) separator, not tab**: tab is IFS whitespace, so an empty field would collapse and shift every later field left. |
| `bin/autopilot.sh` | Toggle the persisted per-repo autopilot flag (`on`/`off`/`status`), **ship-mode** (`ship on`/`off`/`status`, R34), **decisive mode** (`decisive on`/`off`/`status`, R59 — auto-decide reversible, park only irreversible), and **sweep mode** (`sweep on`/`off`/`status`, R77 — also work parks marked `rev:`). |
| `bin/stop-autopilot.sh` | Stop hook: while autopilot is on and non-deferred work remains, auto-continue the drain (no-progress capped); yields when nothing workable remains. **Sweep (R77):** with the flag on, a `❓` the parker MARKED `rev:` (and carrying an anchored `rec:`) counts as workable, so the drain no longer yields on a parked-only queue. No marker ⇒ irreversible ⇒ never swept; `⏳` and `decompose:` never, in any mode. Eligibility is code keyed on a marker `ask-guard.sh` writes — not an inference over prose. Carries its OWN terminator: the stall cap can't bound a sweep (completing a swept park resets it), so a counter no completion resets yields at the same cap. **Ship-mode (R34):** also auto-commits each turn's work to an `autopilot/*` branch (never the default, never a push), best-effort. **RUN bounds (R81):** the no-progress cap catches a STUCK model but never a BUSY one (`stall` resets on every completion), so a productive drain had no terminator — two generous bounds now end an unattended runaway: `CLAUDE_COMPANION_AUTOPILOT_HOURS` (6, wall-clock, includes suspend — the safe direction) and `CLAUDE_COMPANION_AUTOPILOT_TURNS` (400, suspend-immune), whichever fires first; `0` disables either. `CLAUDE_COMPANION_AUTOPILOT_CONTINUE=0` disables the continue. |
| `bin/ask-guard.sh` | PreToolUse[AskUserQuestion] hook: deny asking while autopilot is on (decide-if-reversible or park as ❓). Silent when autopilot is off. |
| `lib/companion.sh` | Shared helpers (flag encoding/paths, repo root, open-task scan) — sourced by autopilot, the Stop hook, ask-guard, session-start/resume, and the status line, so the encoding can't drift. |
| `commands/setup.md` · `commands/autopilot.md` | `/companion:setup` (status line) · `/companion:autopilot [on\|off\|status \| ship … \| decisive …]` (toggle; empty → status). |
| `bin/tq prune` | Age-based prune of THIS repo's FINISHED session stores (`--days N`, default 90; `--dry-run`). Deliberately a CLI command and **not** a hook — R68 forbids a hook deleting. Fail-safe in every direction: any open/parked/blocked task keeps the store, an unreadable file keeps it (jq's EXIT STATUS is the guard, not its stdout), symlinked dirs are skipped (`rm -rf` would recurse through the link), and another project's stores are invisible. |
| `bin/da-gate.sh` | The R78 devil-advocate gate, extracted from `ship.sh` at its 300-line cap. `note` validates the `--da` finding and REFUSES a rubber stamp (bare `clean`/`none`/`lgtm`, or under 24 chars) — a stamp launders the decision instead of testing it (R53). `match` reads changed paths and reports the critical ones, stripping comments first (`grep -Ef` compiles every line, so a paren in a comment silently disabled the whole gate) and FAILING CLOSED on an unusable config. Fails CLOSED on an unreadable/directory/invalid config, strips CR so a Windows checkout cannot silently disable it, and honours NO env override (an earlier `DA_PATHS_FILE` was a trace-free kill switch). Cannot verify a pass actually ran — no shell check can; it makes skipping deliberate. |
| `hooks/hooks.json` | Wires SessionStart · PreToolUse[Write\|Edit\|NotebookEdit (secret-guard) + AskUserQuestion (ask-guard)] · Stop (stop-autopilot). *(UserPromptSubmit/`capture.sh` removed 2026-07-29 — R58(a) retired, see REQUIREMENTS.)* |
| `.claude-plugin/plugin.json` | Manifest + version. |
| `tests/companion-{core,hud,fuzz,ship}.bats` | Test the **enforced core only** — `core` (secret gate · `tq` · session-start/resume · autopilot), `hud` (status line), `fuzz` (every hook survives empty/garbage/huge/emoji stdin — R30·d8), `ship` (the rail's guards: bail-before-damage, never-default-delete, list-only sweep — R71). The steering layer is prose; it isn't unit-testable, and pretending it was is what the old system got wrong. |
